## 1. 브랜드 디자인 콘셉트 및 시각 설계 원칙

### 1-1. 디자인 콘셉트: **Quiet Clinical Authority (절제된 전문성과 프라이빗 신뢰)**
- **핵심 지향점:** 1999년부터 이어온 정통 비뇨의학의 임상 권위, **박천진·이웅희 2인 전문의 협진**, **구독자 5.2만+ 공식 유튜브(`@uroj`)**의 투명한 정보 전달, 그리고 비뇨기과 환자가 가장 중시하는 **프라이버시와 심리적 안정감**을 절제된 에디토리얼 레이아웃으로 구현합니다.
- **표현 배제 원칙 (Anti-Patterns):**
  - **SaaS 대시보드화 금지:** 얇은 `1px` 회색 테두리의 네모난 카드를 기계적으로 나열하지 않으며, 그림자 남발을 지양합니다.
  - **자극적 의료 비주얼 금지:** 수술 원색 사진, 비포/애프터 비교 슬라이더, 과장된 이벤트 배너, AI 생성 인물/병원 이미지를 사용하지 않습니다.
  - **여백과 면 대비(Color Surface) 중심 설계:** 섹션 간 배경 톤 전환(`Pure White` ↔ `Soft Cool Surface` ↔ `Warm Paper` ↔ `Deep Navy`)과 넉넉한 상하 여백으로 시각적 호흡을 만듭니다.

### 1-2. 사용자 영역 vs 관리자 영역 UI 톤 분리 원칙
- **사용자 사이트 (`/` ~ `/account`):** 에디토리얼 메디컬 브랜드 톤 — 넓은 여백, 면 대비 중심, 보더 최소화, 큰 타이포그래피 위계.
- **경량 관리자 (`/admin/*`):** 실무 효율 중심의 정돈된 클리니컬 워크스페이스 — 동일한 브랜드 컬러 토큰(`Deep Navy`, `Trust Blue`)을 공유하되, 테이블·필터·상태 배지 가독성을 우선하는 컴팩트 밀도로 분리 적용.

## 6. 웹 접근성(A11y) 및 반응형 검증 기준 (STEP 7 QA 연계)

1. **색상 대비:** 모든 본문 텍스트 및 상태 배지는 **WCAG 2.1 AA(`4.5:1` 이상)** 충족.
2. **키보드 내비게이션:** PC GNB 드롭다운, 가로 슬라이드 이전/다음, 유튜브 모달(포커스 트랩 + `ESC`), 동의서 아코디언, 폼 전체를 키보드만으로 조작 가능.
3. **터치 타깃:** 모바일 모든 인터랙티브 버튼·체크박스·하단바 아이템 최소 **`44×44px`** 확보.
4. **반응형 무결성:** `1920px`, `1440px`, `1280px`, `390px`, `375px` 5개 해상도에서 가로 스크롤(`document.documentElement.scrollWidth <= window.innerWidth`) **0px** 검증.
5. **시맨틱 마크업:** 페이지당 단일 `<h1>`, 논리적 `<h2>`→`<h3>` 위계, 모든 `<img>` 의미 있는 `alt` 속성(장식용 `alt=""`).

## 7. STEP 3 종료 체크리스트 (마스터 프롬프트 13번 기준)

### 1. 완료된 작업
- **Quiet Clinical Authority** 브랜드 콘셉트 및 SaaS 템플릿화 방지(면 대비·충분한 여백·보더 최소화) 규칙 수립 완료
- Tailwind CSS v4 / shadcn/ui 매핑용 컬러·타이포그래피·스페이싱·라디우스·상태 배지·모션 토큰 정의 완료
- 8대 공통 UI 컴포넌트(헤더/GNB, 다크 푸터, 모바일 4버튼 고정바, 모바일 `390px` 7컬럼 `table-layout: fixed` 2인 진료시간표, 유튜브 `@uroj` Facade+모달, 의료법 부작용 고지 박스, PC 휠/모바일 터치 가로 슬라이드, 미확보 이미지 슬롯) 명세 완료
- 비회원 온라인 예약 폼, 경량 회원(`MEMBER`) 인증/계정 폼, 일반·민감정보 분리 동의 박스, 1:1 비밀상담 목록/상세 UI 규격 정의 완료
- 핵심 5개 화면(메인, 진료 상세, 온라인 예약, 1:1 비밀상담, 관리자 대시보드)의 PC(`1440px`)·모바일(`390px`) 와이어프레임 작성 완료 (코드 작성 0건)

### 2. 결정된 사항
- **컬러·톤:** Deep Navy(`#0F253E`) + Trust Blue(`#1D5B9B`) + 절제된 Warm Brass(`#9A7B4F`) + Surface 0/1/2 면 대비 체계 확정
- **반응형 핵심 규격:** 히어로 `100svh` 안전 높이, 모바일 좌우 `20px` 통일 여백, 2인 진료시간표 모바일 7컬럼 `table-layout: fixed`, 가로 슬라이드 PC 휠 ↔ 모바일 네이티브 스와이프 전환
- **모바일 고정바:** 4버튼(`전화상담` · `온라인 예약` · `1:1 비밀상담` · `오시는 길`) + 푸터 하단 `88px` 안전 여백
- **상담/예약 상태 배지:** `접수됨(슬레이트)` / `확인중(앰버)` / `답변완료·확정(블루)` / `종료·휴진(뉴트럴 그레이)` 통일

### 3. 미확정 사항 (고객사 확인 대기)
- 박천진·이웅희 원장 고해상도 원본 프로필 사진 수령 시점 (미수령 시 `[임시 이미지 - 실제 촬영본 교체 필요]` 슬롯으로 1차 구현)
- 메인 히어로 및 시설 갤러리 최종 선별 사진 6~10장 확정(기존 `assets/real-hospital/` 31건 중)
- 오시는 길 카카오맵 JS API 키 발급 주체(병원 사업자 계정 vs 개발 계정)

### 4. 위험 요소
- **PC 휠 연동 가로 슬라이드 사용성 리스크:** 트랙패드·고속 휠 환경에서 스크롤 갇힘(Scroll Hijacking) 불쾌감 발생 가능 → 좌우 버튼 병행 + 자연스러운 섹션 진입/이탈 임계값 설계 및 `prefers-reduced-motion` 시 일반 그리드/가로 스크롤 폴백 필수
- **원본 인물 사진 미확보 시 시각적 완성도 저하:** 메인 2인 전문의 섹션의 신뢰도에 직결되므로 개발 착수 전 고객사 원본 사진 요청 병행 필수
- **모바일 `390px` 7컬럼 표 가독성:** `수술/진료` 텍스트가 `375px` 소형 기기에서 넘칠 위험 → `10.5px` 컴팩트 2줄 처리 또는 범례 축약(`수술·진료`) 실측 테스트 필수
