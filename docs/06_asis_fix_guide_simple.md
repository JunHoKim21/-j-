# 강남J비뇨기과 홈페이지 리뉴얼 — 왜 고쳐야 할까요? (쉬운 안내서)

- **작성일:** 2026-11-26
- **대상:** 병원 원장님 · 관계자 · 소개자분
- **내용 요약:** 기존 홈페이지(`manclinic.com`)를 점검하면서 발견된 **"환자가 불편하거나 법적으로 위험한 부분"**을 쉬운 말로 정리한 안내서입니다.

## 1. 홈페이지 보안과 첫인상 ("안전한 자물쇠와 스마트폰 화면")

| 기존 홈페이지 문제 | 새 홈페이지에서 바뀌는 점 | 병원에 좋은 점 |
|---|---|---|
| **주소창에 '주의 요함' 경고 표시 (`HTTP`)** | **보안 자물쇠(`HTTPS`) 전면 적용** | 환자가 접속할 때 불안해하지 않고, 네이버·구글 검색에서도 안전한 병원으로 평가받습니다. |
| **PC·모바일 홈페이지가 따로 놀음** | **화면 크기에 맞춰 자동 변형 (하나로 통합)** | PC, 아이패드, 스마트폰 어디서 보든 글자가 잘리거나 깨지지 않고, 앞으로 공지·시간표를 한 번만 고치면 됩니다. |
| **예전 방식 화면 틀과 깨진 글자 위험** | **최신 웹 표준 방식으로 전면 재제작** | 페이지 열리는 속도가 훨씬 빨라지고, 최신 브라우저에서도 오류 없이 깨끗하게 보입니다. |

## 2. 네이버 · 구글 검색 순위 지키기 ("27년 단골 길목 보존")

- **예전 주소를 새 주소로 자동 안내 (주소 연결 기능):**
  - 1999년부터 쌓아 온 옛날 인터넷 주소(`/@2018/...`, `m.manclinic.com/...`)를 통해 들어오는 환자분들이 "페이지를 찾을 수 없습니다(404)" 화면을 보지 않도록, **새 홈페이지의 알맞은 페이지로 자동 연결**해 검색 순위를 그대로 지켜드립니다.
- **모바일 '통사진' 페이지 → 읽을 수 있는 글자로 교체:**
  - 기존 모바일 질환 안내 페이지 6개는 글자가 아니라 **큰 통사진 1장**으로 되어 있어 스마트폰에서 글씨가 깨알처럼 작아지고, 네이버·구글이 내용을 읽지 못했습니다.
  - 이를 **검색이 잘 되는 선명한 글자와 그림**으로 바꿔 검색 노출과 환자 가독성을 동시에 높입니다.

## 3. 헷갈리는 병원 정보와 고장 난 버튼 바로잡기

기존 PC와 모바일을 비교해 보니 서로 말이 다른 부분과 누르면 오류가 나는 버튼들이 꽤 많이 발견되었습니다. 새 홈페이지에서는 이를 하나로 깔끔하게 맞춥니다.

1. **의료진 안내 통일:** 기존 PC에는 옛날 의료진 정보가 남아 있었는데, 최신 안내 기준인 **박천진 대표원장 · 이웅희 원장 2인 협진 체제**로 정확히 맞춥니다.
2. **진료시간·휴진일 통일:** 본문(`수요일 휴진`)과 최근 안내(`이웅희 원장 목 휴진 / 박천진 원장 월·목 오후 휴진`)가 서로 달랐던 문제를 최신 기준 표 하나로 통일합니다.
3. **상담시간 통일:** 어떤 곳은 9~18시, 어떤 곳은 8~20시, 어떤 곳은 24시간으로 다르게 적혀 있던 문구를 병원의 실제 공식 상담시간으로 맞춥니다.
4. **전화번호 오연결 수정:** 모바일 화면 하단에 적힌 번호(`010-9190-7575`)를 눌렀는데 실제로는 다른 번호(`010-3168-8275`)로 걸리던 오류를 고쳐 모두 정상 번호로 연결합니다.
5. **다른 사이트로 튕겨 나가는 문제 해결:** 모바일에서 '오시는 길'을 누르면 엉뚱한 다른 사이트(`penisdoctor.co.kr`)로 넘어가던 문제를 없애고, 우리 홈페이지 안에서 바로 학동역 약도를 보여줍니다.
6. **고장 난 메뉴·FAQ 및 진행 중 상담 정리:**
   - 누르면 없는 페이지가 뜨던 링크 14곳과 깨진 그림 2곳을 모두 정리합니다.
   - 모바일 메뉴에서 빠져 있던 `요로결석` 메뉴를 복구하고, 이름이 잘못 적혀 있던 `남성확대수술` 메뉴를 바로잡습니다.
   - `조루증` 하위 메뉴들이 전부 첫 화면으로만 가던 오류와, `고환 FAQ`에 전립선 질문이 잘못 들어가 있던 오류를 수정합니다.
   - **진행 중인 상담 이어가기:** 기존 상담실에 답변 대기 중인 최근 글들은 오픈 전 일괄 회신해 마무리하거나 1~3개월간 구 사이트를 임시 병행해 고객 문의가 끊기지 않도록 처리합니다.

## 4. 의료법 · 개인정보보호법 안전 지키기 ("병원 보호막")

비뇨기과는 환자분들이 민감해하는 진료 과목이라 법적 기준을 꼼꼼히 지키는 것이 매우 중요합니다.

1. **'일반 개인정보'와 '건강(민감)정보' 동의 따로 받기:**
   - 기존에는 동의 체크란이 1개뿐이었고, 심지어 글자를 눌러도 체크가 안 되는 오류도 있었습니다.
   - 새 홈페이지에서는 이름·연락처 같은 **일반 정보 동의**와 증상·진료 내용 같은 **건강정보(민감정보) 별도 동의**를 법에 맞게 2개로 나누어 안전하게 받습니다.
2. **오래된 개인정보처리방침 새로 쓰기:**
   - 기존 약관에 남아 있던 아주 옛날 문구(`주민등록번호 수집`, `넷스케이프`, 옛 외주업체 이메일 등)를 모두 지우고 현재 법에 맞는 최신 내용으로 바꿉니다.
3. **'환자 감사편지(Thanks Letter)' 정리:**
   - 로그인하지 않은 누구나 볼 수 있게 올라와 있던 수술·임신 성공 후기 글은 현재 **의료법(치료경험담 금지)상 문제 소지**가 있어, 새 홈페이지에서는 비공개 정리하여 병원을 법적 위험으로부터 보호합니다.
4. **위험한 과장 문구 완화 & 부작용 안내문 추가:**
   - `"통증·출혈·합병증 없음"`, `"평생 걱정 없는 가장 확실한 치료법"`처럼 법적으로 문제가 될 수 있는 단정적 표현은 신뢰감 있는 의학 설명으로 다듬고, 모든 시술 안내 아래에 **부작용·주의사항 안내 박스**를 기본으로 넣습니다.
5. **비급여 비용표 최신화:**
   - 법적으로 반드시 공개해야 하는 비급여 진료비용표를 건강보험심사평가원 신고 금액과 100% 맞춘 뒤 홈페이지 하단에 항상 보이게 배치합니다.
