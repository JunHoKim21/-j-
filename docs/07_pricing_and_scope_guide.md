# 강남J비뇨기과 홈페이지 리뉴얼 — 견적·과업 범위(Scope) 및 계약 기준서

> **목적:** 350만 원 수주 시 작업 범위(Scope)를 명확히 구분하여 **수주 측의 적자(무한 수정·DB 이관 공수 폭발)를 방지**하고, 병원 측에도 **투명하고 합리적인 선택지**를 제시하기 위한 내부 기준 및 계약 협의용 문서입니다.

---

## 1. 핵심 판단: 350만 원은 합리적인가?

* **합리적인 경우 (기본형 스코프):**
  이미 1차·2차 시안(`web` 48개 라우트 / `web-v2` 54개 라우트)으로 디자인·퍼블리싱 뼈대가 잡혀 있는 상태에서, **반응형 구축 + 보안(HTTPS)/301 연결 + 간편 상담/네이버예약 연동**까지만 진행한다면 350만 원은 시장 평균(300~500만 원대 병의원 홍보형 사이트) 안에서 **충분히 합리적**입니다.
* **적자가 되는 경우 (풀옵션 무상 포함):**
  **기존 회원 DB 이관 + 기존 상담 게시판 마이그레이션 + 자체 관리자(CMS) + 회원제 비밀글 시스템**까지 350만 원에 모두 포함하면 실제 난이도는 **600~1,000만 원대 웹 애플리케이션 구축**으로 커져 명백한 적자가 됩니다.

## 2. 계약 제시용 패키지 및 옵션 구조 (권장)

미팅·계약 단계에서는 "350만 원에 전부 해드립니다"가 아니라 **기본형과 선택 옵션을 분리해서 제시**하는 것이 가장 안전합니다.

| 구분 | 포함 범위 | 권장 금액선 | 비고 |
| :--- | :--- | :---: | :--- |
| **기본형 (제안가)** | • PC/모바일 통합 반응형 리뉴얼 (시안 기반)<br>• HTTPS(SSL) 적용 및 기존 핵심 URL 301 리다이렉트<br>• 메타태그/사이트맵 등 기본 SEO 정비<br>• **간편 상담 신청**(메일/알림톡/문자 알림) + **네이버 예약·카카오 채널 연동**<br>• 일반/민감정보 분리 동의 UI 적용 | **350만 원** | 회원 로그인 및 자체 게시판 DB 제외 |
| **옵션 A (선택)** | • **기존 회원 DB 및 온라인 상담 내역 이관**<br>• 기존 비밀글·답변·첨부파일 매핑 및 인코딩/암호화 호환 처리 | **+150~250만 원** | 기존 서버 소스·DB 구조 사전 확인 후 최종 확정 |
| **옵션 B (선택)** | • **자체 관리자 페이지(CMS) 및 회원제 비밀글 상담 시스템** 신규 구축<br>• 원장님/직원 답변 관리, 공지·비급여표 어드민 수정 기능 | **+150~250만 원** | 백엔드·인증·접근제어 보안 테스트 포함 |

## 3. 계약서·합의서에 반드시 명시해야 할 방어 조항 4가지

350만 원 프로젝트에서 공수가 터지는 원인은 대부분 개발보다 **범위 모호성과 수정 지연**입니다. 아래 4가지를 계약 시 명문화해야 합니다.

1. **수정 범위 및 횟수 제한**
   * 확정된 시안 기준 **디자인 레이아웃 수정 2회, 텍스트/이미지 교체 2회** 이내로 제한.
   * 전체 컨셉 변경이나 신규 페이지 추가는 별도 견적으로 산정.
2. **병원 측 자료 전달 기한 및 일정 연동**
   * 착수 전 필요 자료(① 의료진 고해상도 사진 ② 확정 진료시간표·비급여표 ③ 유튜브 선별 목록) 전달 지연 시, 전체 납기 일정도 동일하게 순연됨을 명시.
   * 실제 촬영이 필요한 사진은 병원 측 제공 원칙(촬영 대행 미포함).
3. **기존 데이터/소스 확인 조건 (옵션 A 해당 시)**
   * 기존 홈페이지 관리자 계정, FTP/SSH 소스 접근 권한, DB 덤프 제공이 전제되어야 하며, 레거시 암호화·손상 데이터 복구 불가 시 대안(예: 기존 회원 비밀번호 재설정 안내, 진행 중 상담건만 수동 이관 등)으로 협의.
4. **의료법·개인정보 법적 책임 구분**
   * UI 상의 필수 고지(시술 주의사항 영역, 일반/민감정보 동의 분리)는 반영하되, **최종 게시 문구의 의료법 제56조(의료광고 심의) 적합성 및 개인정보 처리방침 법률 검토 최종 책임은 병원 측**에 있음을 명시.

## 4. 미팅·계약 시 추천 화법

* *"350만 원 기본형은 **디자인·반응형 구축·보안(HTTPS)·검색 순위 보존(301)·간편 상담/네이버 예약 연동**까지 포함된 실속형 패키지입니다."*
* *"다만 **기존 회원 DB나 예전 상담 게시판을 새 사이트로 그대로 옮기거나, 원장님 전용 관리자 페이지를 새로 만드는 작업**은 서버·DB·보안 작업이 별도로 들어가기 때문에, 기존 사이트 DB 구조를 확인한 뒤 **선택 옵션**으로 깔끔하게 나눠서 진행하는 것이 서로에게 안전합니다."*
* *"만약 진행 중인 기존 상담만 이어가시면 되는 거라면, 굳이 무거운 DB 이관(옵션 A) 비용을 들이지 않고 **진행 중인 건만 정리해서 인계받으시거나 네이버 톡톡/카카오 채널·간편 상담으로 전환**하시는 편이 비용 면에서 훨씬 유리합니다."*
